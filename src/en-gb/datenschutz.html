3. Hosting and server log files

The provider of these pages, GitHub Pages, automatically collects and stores information in so-called server log files, which your browser automatically transmits to us or to the host. This generally includes:

  • Browser type and browser version
  • Operating system used
  • Referrer URL (the previously visited page)
  • Hostname of the accessing computer (IP address)
  • Time of the server request
  • Page/file accessed

As a rule, this data cannot be attributed to specific individuals. This data is not merged with other data sources. The legal basis for data processing is Article 6(1)(f) UK GDPR, which permits the processing of data for the purposes of our legitimate interests in ensuring the technically error-free presentation and optimisation of our website.

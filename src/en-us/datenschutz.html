3. Hosting and Server Log Files

The provider of the pages, GitHub Pages, automatically collects and stores information in so-called server log files, which your browser automatically transmits to us or to the host. These are generally:

  • Browser type and browser version

  • Host name of the accessing computer (IP address)
  • Time of the server request

As a rule, this data cannot be assigned to specific individuals. This data will not be merged with other data sources. The basis for data processing is Art. 6 (1) (f) GDPR, which permits the processing of data for the fulfillment of a contract or pre-contractual measures, as well as to safeguard our legitimate interests in a technically error-free presentation and optimization of our website.
